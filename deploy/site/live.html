Run it yourself

This starts a real agent on a cloud GPU (NVIDIA T4, model qwen2.5:7b). It works on one coding task, once through raw Ollama and once through ContextGC, with the same 8k context window. You can watch every step.

The first minute or two is the GPU starting and the model loading. Each lane then takes about 1–4 minutes. Only one run happens at a time; if someone else's run is going, you'll watch that one.
